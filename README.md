# 808 · AFTERHOURS

Heavy 808 bass instrument (VST3 + AU, macOS) from the **AFTERHOURS** trap/rage pack. Same sound engine as the
browser prototype: sine oscillator with pitch envelope and glide, waveshaper drive (CLIP / TAPE / FOLD, 4x
oversampled), lowpass TONE, clean SUB path, noise CLICK, punchy amp envelope and 6 presets.

Every push builds the plugin with `.github/workflows/build-mac.yml`. Download `808-mac` from the Actions run,
unzip and double-click `install.command` (or follow `INSTALL.txt`). The plugin shows up under **AFTERHOURS**.
